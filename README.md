# OpenRUS OS - Cyberpunk Edition (x86_64)
> **Настоящая операционная система по твоему эскизу:**
> Фирменный киберпанк-логотип **Медведь**, левая вертикальная панель, трей с Wi-Fi/Bluetooth, автоматические драйверы, запись через **Rufus по MBR в режиме DD**, и **Центр обновлений через GitHub** прямо из системы без переустановки.

---

## 📸 Интерфейс (В точности по твоему рисунку)

```
+---------------------------------------------------------------+
| [ ] [ ] OpenMarket  [ ] Браузер                              |
|                                                               |
| [📊] Диспетчер задач                                          |
| [🎵] MP3 плеер                                                |
| [📁] Проводник                                                |
| [💻] Терминал                                                 |
| [⚙️] Настройки & GitHub                                       |
|  |                                                            |
|  v                                                            |
| [🐻] ПУСК "МЕДВЕДЬ"                 [📶 WiFi] [⚡ BT] 00:00:00 |
+---------------------------------------------------------------+
```

1. **Левая вертикальная панель:**
   - **Диспетчер задач** (Мониторинг реального/симулированного CPU, памяти RAM, SSD NVMe, GPU).
   - **MP3 плеер** (Встроенный синтезатор Synthwave, визуализатор частот, управление треками).
   - **Проводник** (Навигация по разделам диска, загрузкам, системным папкам).
   - **Терминал** (Эмулятор bash с поддержкой команд `openrus-update`, `hwinfo`, `neofetch`, `wifi`, `bt`).
   - **Настройки** (Центр обновления GitHub, проверка драйверов).
   - **Кнопка Пуск «Медведь»** (Фирменное неоновое меню Пуск со статусом системы).
2. **Рабочий стол:**
   - Ярлыки **OpenMarket** и **Браузер**.
3. **Трей в правом нижнем углу:**
   - **Wi-Fi** (Меню выбора сетей и уровня сигнала).
   - **Bluetooth** (Меню сопряжения устройств).
   - **Живые часы и дата** (`00:00:00` в точности по эскизу).

## 🚀 Как запустить и пощупать прямо сейчас на Windows

Просто дважды кликни по файлу:
👉 **`Launch_OpenRUS_Desktop.bat`** (или открой `ui\index.html` в любом браузере)

У тебя откроется полноценная рабочая интерактивная среда:
- Понажимай на кнопку **Медведя** внизу слева.
- Запусти **Диспетчер задач** и **MP3 плеер**.
- Открой **Терминал** и введи команду `openrus-update` или `neofetch`.
- Кликни на иконки **Wi-Fi** и **Bluetooth** в правом нижнем углу.

## 🛠️ Архитектура системы OpenRUS

### 1. Запись через Rufus по MBR в режиме DD
* Образ собирается с помощью гибридной разметки (`isohybrid` + `xorriso`).
* В Rufus выбирается:
  * **Схема раздела:** `MBR`
  * **Режим записи:** `DD-образ` (или ISO)
  * На ноутбуке запускается без ошибок загрузчика на любых накопителях (SATA, NVMe).

### 2. Автоматические драйверы (`system/openrus-auto-drivers.sh`)
* **Wi-Fi:** Модули ядра `iwlwifi` (Intel Wi-Fi 5/6/6E/7), `rtw88`/`rtw89` (Realtek), `mt7921` (MediaTek), `bcmwl` (Broadcom).
* **Bluetooth:** Стек `bluez` с автоматическим автоопределением USB/PCIe адаптеров.
* **GPU & Дисплей:** Автоопределение NVIDIA, AMD Radeon (Mesa Vulkan) и Intel Iris/UHD.
* **Накопители:** Нативная поддержка NVMe SSD и SATA без синих экранов.

### 3. Центр обновлений GitHub (`system/openrus-updater.py`)
* Подключается к твоему GitHub репозиторию через GitHub Releases API.
* Проверяет новую версию: если ты выложил патч — система на ноутбуке скачивает архив `openrus-update.tar.gz`.
* Применяет изменения «на лету» (**in-place**) прямо в рабочей системе без необходимости перепрошивать флешку!

### 4. Установщик системы (Calamares Cyberpunk Theme)
* Расположен в `installer/calamares/branding/openrus/`.
* При загрузке с флешки запускается графический мастер установки в стиле киберпанк с логотипом Медведя.
* Позволяет разметить диск в один клик и установить OpenRUS рядом с другой ОС или на чистый диск.

## 📦 Сборка загрузочного `.iso` файла

Для финальной компиляции файла `OpenRUS-Cyberpunk-v1.0-x86_64.iso` используется скрипт:
```bash
sudo bash iso-builder/build_openrus_iso.sh
```
*(Сборку можно запустить на любом Linux-компьютере, виртуальной машине или через WSL на Windows).*
